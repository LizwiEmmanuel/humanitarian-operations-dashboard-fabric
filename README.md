# Humanitarian Operations & Impact Dashboard (Microsoft Fabric)

## 📊 Project Overview
This project demonstrates an end-to-end analytics solution built using **Microsoft Fabric and Power BI** to analyze humanitarian operations and impact data.

The dashboard simulates a real NGO reporting environment, transforming automated data into actionable insights for monitoring performance, trends, and program impact.

---

## ❗ Problem Statement
Humanitarian organizations often struggle with fragmented data, delayed reporting, and limited visibility into operational performance.

This project addresses those challenges by:
- Centralizing operational data into a single reporting layer
- Tracking key performance indicators over time
- Enabling data-driven decision-making
- Reducing manual reporting through automation

---

## 🛠️ Tools & Technologies
- Microsoft Fabric
- Power BI
- DAX
- Data Modeling (Star Schema)
- Automated Refresh Pipelines

---

## 📈 Key Features
